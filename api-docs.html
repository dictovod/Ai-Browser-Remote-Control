API Reference — v1
Обзор

Два способа отправки команд

Пользователи могут использовать любой из двух способов в зависимости от задачи.

Способ 1 — REST API
POST-запросы через wp-json/brc/v1/command. Подходит для curl, скриптов, n8n, Make, любого HTTP-клиента.
Способ 2 — GET API
Простые GET-запросы через lp85d.ru/api/. Вставляй в браузер, Zapier, no-code инструмент.
Способ 1

REST API — curl / HTTP-клиент

bash 
# scroll
curl -X POST "https://lp85d.ru/wp-json/brc/v1/command" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"browser_id":"YOUR_BROWSER_ID","command":{"type":"scroll","direction":"down","amount":300}}'

# type
curl -X POST "https://lp85d.ru/wp-json/brc/v1/command" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"browser_id":"YOUR_BROWSER_ID","command":{"type":"type","selector":"input[name=email]","value":"test@example.com","clear":true}}'

# click
curl -X POST "https://lp85d.ru/wp-json/brc/v1/command" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"browser_id":"YOUR_BROWSER_ID","command":{"type":"click","selector":"button[type=submit]"}}'

# navigate
curl -X POST "https://lp85d.ru/wp-json/brc/v1/command" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"browser_id":"YOUR_BROWSER_ID","command":{"type":"navigate","url":"https://lp85d.ru/test/"}}'

# eval
curl -X POST "https://lp85d.ru/wp-json/brc/v1/command" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"browser_id":"YOUR_BROWSER_ID","command":{"type":"eval","code":"document.title"}}'

# screenshot
curl -X POST "https://lp85d.ru/wp-json/brc/v1/command" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"browser_id":"YOUR_BROWSER_ID","command":{"type":"screenshot"}}'
Способ 2

GET API — lp85d.ru/api/

Простые GET-запросы без curl. Вставляй в браузер, скрипт или no-code инструмент.

Тип команды Пример URL Описание
scroll https://lp85d.ru/api/?browser_id=YOUR_BROWSER_ID&token=YOUR_API_KEY&allowed_types=scroll&amount=3000 Скролл вниз на 3000px
scroll ↑ https://lp85d.ru/api/?browser_id=YOUR_BROWSER_ID&token=YOUR_API_KEY&allowed_types=scroll&amount=500&direction=up Скролл вверх на 500px
type https://lp85d.ru/api/?browser_id=YOUR_BROWSER_ID&token=YOUR_API_KEY&allowed_types=type&selector=input[name=email]&value=test@example.com Ввод текста по CSS-селектору
type_nth https://lp85d.ru/api/?browser_id=YOUR_BROWSER_ID&token=YOUR_API_KEY&allowed_types=type_nth&nth=3&value=Привет Ввод в 3-е поле на странице
click https://lp85d.ru/api/?browser_id=YOUR_BROWSER_ID&token=YOUR_API_KEY&allowed_types=click&selector=button[type=submit] Клик по элементу
click_coords https://lp85d.ru/api/?browser_id=YOUR_BROWSER_ID&token=YOUR_API_KEY&allowed_types=click_coords&x=640&y=360 Клик по координатам
navigate https://lp85d.ru/api/?browser_id=YOUR_BROWSER_ID&token=YOUR_API_KEY&allowed_types=navigate&url=https://lp85d.ru/test/ Переход на страницу
select https://lp85d.ru/api/?browser_id=YOUR_BROWSER_ID&token=YOUR_API_KEY&allowed_types=select&selector=select[name=country]&value=Германия Выбор значения в дропдауне
checkbox https://lp85d.ru/api/?browser_id=YOUR_BROWSER_ID&token=YOUR_API_KEY&allowed_types=checkbox&selector=input[name=agree]&checked=true Чекбокс вкл/выкл
radio https://lp85d.ru/api/?browser_id=YOUR_BROWSER_ID&token=YOUR_API_KEY&allowed_types=radio&selector=input[value=female] Радиокнопка
eval https://lp85d.ru/api/?browser_id=YOUR_BROWSER_ID&token=YOUR_API_KEY&allowed_types=eval&code=document.title Выполнить произвольный JS
screenshot https://lp85d.ru/api/?browser_id=YOUR_BROWSER_ID&token=YOUR_API_KEY&allowed_types=screenshot Скриншот текущей страницы
🔐
token — твой API ключ из вкладки Dashboard. browser_id — ID нужного браузера из вкладки Browsers.
Ответ

Формат ответа

Ответ одинаковый в обоих случаях — JSON с результатом выполнения команды.

✅ Успех
{
  "status": "sent",
  "http_code": 200,
  "api_response": {
    "command_id": 72,
    "type": "screenshot",
    "status": "executed",
    "result": "Screenshot saved,
downloadId: 814",
    "waited_sec": 6
  }
}
❌ Ошибка
{
  "status": "error",
  "http_code": 401,
  "message": "Invalid API key"
}

# Превышение лимита
{
  "status": "error",
  "http_code": 429,
  "message": "Rate limit exceeded"
}
